# Матрица функций

Проверено 19 сентября 2026 года по опубликованной OpenAPI 3.1 и безопасным запросам к рабочему API. «Требует аккаунт» означает, что маршрут и экран реализованы, но сквозная проверка не выполнялась без тестового пользователя.

| Функция | API | Экран | Реализация | Проверка |
|---|---|---|---|---|
| Главная, подборки, баннеры, истории | `stores/{id}/product-groups`, `banners`, `stories` | `/` | Готово, пустые истории скрываются | Живые данные, Chrome |
| Каталог и категории | `stores/{id}/categories`, `children`, `products` | `/catalog`, `/category/:id` | Готово, URL-пагинация | Живые данные, Chrome |
| Поиск и подсказки | `search/stores/{id}/products`, `filters`, `search/suggestions` | `/search?query=` | Готово, запрос/фильтры в URL | Живые данные, Chrome |
| Фильтры и сортировка | category/search filters | Каталог/поиск | Desktop sidebar, mobile sheet | Маршруты проверены |
| Подборки | product groups by slug | `/collection/:slug` | Готово, постоянный URL | Живые данные |
| Товар, варианты, добавки | `products/{id}`, similar, related | `/product/:id`, быстрый просмотр | Готово, связанные группы нормализуются | Живые данные, Chrome |
