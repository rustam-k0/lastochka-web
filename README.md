# Ласточка Джами — веб-магазин

Адаптивная Next.js-витрина существующего Laravel-магазина. Коммерческие данные, доступность, корзина и заказы остаются на `https://lastochki.store/api/v1`; браузер общается с ним только через серверный слой Next.js.

## Локальный запуск

```sh
cp .env.example .env.local
# заполнить SESSION_ENCRYPTION_KEY: openssl rand -hex 32
npm ci
npm run dev
```

Проверки: `npm test`, `npm run typecheck`, `npm run build`, `npm run test:e2e`.

## Настройка

- Дизайн: CSS-переменные в `app/globals.css` (`--brand`, `--radius`, `--content`, адаптивные точки).
- Порядок и подписи блоков: `src/config/content.ts`.
- Разрешённые серверные операции: `src/config/routes.json`, сформированный из OpenAPI.
- Магазин по умолчанию: `DEFAULT_STORE_ID`; после входа активный адрес и выбранный магазин имеют приоритет.
- Покупка: `CHECKOUT_ENABLED`. На продакшене оставлять `false`, пока не приняты тестовый аккаунт и платёжный return URL.

Товарный контент, цены, остатки, изображения, категории, баннеры, FAQ и контакты меняются в существующей серверной админке, а не в репозитории. Файл `src/config/content.ts` — только конфигурация представления и не является административной панелью.

См. [матрицу функций](docs/feature-matrix.md) и [обновление/откат](docs/deployment.md).
